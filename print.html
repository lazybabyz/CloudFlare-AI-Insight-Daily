AI洞察日报 2026/3/8

AI 日报

今日AI资讯

  1. OpenAI 推出 Codex Security：该 应用安全代理 旨在帮助开发者 保护代码库，通过 发现漏洞、验证漏洞 并 提供修复建议 来简化安全流程，使团队能专注于关键问题并 更快地发布代码。

  3. Gemini 的创新应用：有用户通过 Gemini 获取新产品创意，甚至 麦当劳 CEO 也利用 Gemini 来 构思新产品，例如在 McChicken Big Mac 中加入“牛肉味 notes”和“口感”的描述。
  4. Nano Banana 2 创作征集：GeminiApp 正在征集用户使用 Nano Banana 2 进行的创意作品，鼓励用户在回复中分享他们的创作。
  5. AI 编程助手集成：Claude Code / Codex CLI 已集成到 OpenClaw 中，支持通过 Telegram 或 Discord 与 AI 编码助手进行交互，提供 流式响应、内联权限按钮、持久化会话 和 零配置代码。
  6. 开源社区新项目涌现：在 Claude Code 和 Codex 的 Skills 开源后，出现了许多类似的项目，引发了社区的关注和讨论。
  7. Kimi 和 MiniMax 的海外收入增长：数据显示，Kimi 在 2026 年 1 月和 2 月的 Stripe 订单数 呈现 爆炸式增长，从月均不足百名飙升至前列。MiniMax 也实现了显著增长，其订单量约为 Kimi 的三分之一。
  8. Grok 和 Manus 的市场表现：Grok 在 2026 年 2 月跃升至 Stripe 订单排行榜首位，可能与其在推特的“脱衣”功能带来的流量有关。Manus 自 2025 年 3 月上线以来，表现稳步提升，并在 2025 年 11 月后稳定在前五名。
  9. CodeX App 远程控制更新：新发布的 Skills 允许用户 远程控制 CodeX App，并自动进行配置引导，同时修复了部分已知问题，建议用户卸载并重新安装以获得最佳体验。
  10. AI 账号注册与数据利用的灰色地带：有行业人士揭示，部分 AI 账号利用 盗刷信用卡 进行批量注册，并可能通过 “套壳逆向” 的方式出售破解后的聊天接口。此外，云厂商的算力抵扣额度 也存在灰色流转。
  11. 模型蒸馏与数据价值：文章指出，一些 AI 中转站的真正核心商业模式可能是通过收集用户的 Prompt 和 Response 数据，用于 模型蒸馏，实现“一鱼两吃”——既收费，又提供训练数据。
  12. OpenAI GPT-4.5 与 o1 pro 的评价：除了编程 Agent 领域，OpenAI 的 GPT-4.5 和 o1 pro 被认为是行业内的 巅峰之作。

AI 日报

今日AI资讯

  1. OpenAI 与 美国国防部 达成协议，将在其机密网络中部署 AI模型。OpenAI 强调国防部对安全表现出深切尊重。协议签署的同一天，特朗普下令联邦政府全面停止与 Anthropic 的合作。协议内容包含 OpenAI 的两条核心安全原则：禁止国内大规模监控，以及武力使用必须由人类负责。OpenAI 模型将仅在云端部署，不进入边缘设备，并派驻持有安全许可的工程师监控。
  2. OpenAI 正在与美国国防部谈判一份 AI 部署合同。据报道，Sam Altman 在周五的全员会上向员工通报了谈判进展，合同尚未签署。五角大楼接受了 OpenAI 提出的安全红线：不用于自主武器、不搞国内大规模监控、不做关键决策，而这些条件与 Anthropic 坚持的几乎一致。
  3. 著名游戏主播 PewDiePie 利用 Qwen2.5 模型，结合 Deepseek 和清华大学的论文，成功训练出自己的本地大模型，并在基准测试中超过 ChatGPT。他使用的硬件是中国购买的魔改 4090 显卡，这为各国建立自有模型提供了示范。
  4. codex 5.3 版本在处理复杂的软件工程任务时表现出色，能够绕过 HuggingFace 的 KV 缓存抽象，并处理 M-RoPE 等高级技术。
  5. Kling 3.0 在 Artificial Analysis Video Arena 的文本生成视频评测中，再次获得第一名，在“有音频”和“无音频”类别中均超越了 Grok Imagine、Runway Gen-4.5 和 Veo 3.1。
  6. LiteLLM 项目被推荐用于管理 API key，相当于在本地搭建了一个 OpenRouter，方便管理和使用各种模型的 API。它还提供可视化 Web 界面来管理模型配置。
  7. 作者使用大疆 mic3 和 Claude (CC) 实现了智能音频处理。通过将外接磁盘命名为 DJI，Claude 能够自动识别并读取磁盘内容，调用 Whisper3 Large 进行语音转录，并将结果存入 Obsidian 的指定文件夹，效率极高。
