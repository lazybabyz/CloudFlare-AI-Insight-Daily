AI洞察日报 2026/2/4

AI 日报

今日AI资讯

  1. Codex App 于今日推出 macOS 客户端，支持 Skills、MCP 一键安装，并内置常用 Skills，可与 Atlas 浏览器、Figma、Github、Notion 等应用集成，还支持自动化定时操作。界面简洁，对新手友好，值得安装。
  2. OpenAI 为庆祝 Codex App 的发布，将 付费套餐 的速率限制翻倍，并增加了免费用户的访问权限。
  3. Codex App 现已推出 macOS 版本，Windows 版本也将很快发布。为庆祝新品上线，Plus、Pro、Business、Enterprise 和 Edu 用户的速率限制将翻倍，持续两个月，覆盖 Codex App、CLI、IDE 扩展和云服务。
  4. Codex App 允许用户多任务并行处理，通过 worktrees 隔离 Agent 变更，可以创建和使用 Skills（将工具和约定打包成可复用能力），并设置自动化工作流，通过计划任务在后台委托重复性工作给 Codex。
  5. Codex App 的一个新功能允许用户配置其个性，可在 Codex App 中选择预设的个性化模式，例如“经验丰富的工程师”或“友好的编程伙伴”。
  6. Codex App 在发布第一天就获得了超过 20 万的下载量，用户似乎对其表现非常满意。
  7. Codex App 的 macOS 版本已发布，用户反馈其体验超出预期，是一个重大的进步，未来将有更多功能推出。
  8. Codex App 的用户体验被赞为“非常出色”，相较于传统的终端和 Emacs 用户，使用 Codex App 后，返回终端感觉像是“回到过去”，称其为“代理原生构建界面”。
  9. Gemini App 正在测试一项新功能，允许导入其他 AI 平台的聊天记录，但用户需注意，导入的数据将用于模型训练。
  10. Gemini Prompt Tip：在给 Gemini 设置Persona 时，使用简单的职位头衔（例如“作为一名 [职业]…”）能获得更好的响应效果。
  11. Kimi K2.5 的技术报告在 Huggingface 本月论文中排名第二，解释了 K2.5 效果出色的原因，其核心突破在于文本和视觉的“共生”，而非“拼接”。
  12. Kimi K2.5 采用“原生多模态预训练”方式，从训练初期就融入少量视觉数据，实现了文本和视觉能力的协同进化。
  13. K2.5 的 Zero-Vision SFT 技术，能够仅通过文本激活模型的视觉能力，将图像操作转化为代码，实现跨模态的工具使用。
  14. K2.5 的 Agent Swarm 架构实现了从串行到并行的范式转变，通过“总调度者”和“专业小助手”的协作，显著提升了复杂任务的处理效率。
  15. Kimi K2.5 的视觉编码器 MoonViT-3D 采用“时空块”设计，参数共享并有效扩展了上下文窗口，在长视频理解任务上刷新了 SOTA。
  16. K2.5 在强化学习工程实践中采用了 Toggle 算法平衡质量和效率，并使用 Generative Reward Models (GRM) 提供细粒度反馈。
  17. Kimi K2.5 在多个维度上展现了业界顶尖的性能，包括数学竞赛、科学推理、多模态理解和智能体能力等方面。
  18. Kimi K2.5 并非完美，在某些基准上仍落后于领先模型，且 Agent Swarm 在极端复杂场景下的稳定性有待验证，但其在通往通用智能的道路上迈出了坚实一步。
  19. Codex App 的 macOS 客户端存在一些问题，包括模型运行速度慢以及与 Skills 的适配不佳，但 OpenAI 为 Pro 和 Plus 用户的 Codex 额度翻倍。
  20. 有用户反馈 Codex App 的 macOS 版本存在配置文件错误和登录 Key 刷新问题，并提供了相应的解决方法。
  21. 有用户认为 Codex 模型可能是开发某个软件的“Vibe coding”方式，因为该软件存在大量 bug。
  22. NotebookLM 移动应用现已支持视频摘要功能，并可在全屏模式下观看，用户可以直接在手机上生成和观看视频摘要。
  23. 中国科技巨头在 AI 领域的竞争激烈：字节跳动的豆包利用抖音流量和方言细节成为日活破亿产品；腾讯在 Yao Shunyu 加入后发力追赶，元宝整合 DeepSeek 并迅速增长；阿里则以全栈能力对标谷歌，从芯片到云再到应用全面布局。
  24. 中国 AI 厂商在人才争夺和算力投入上不遗余力，字节、阿里、腾讯均拥有超过 10 万张 GPU，并以高标准招聘顶尖人才。
  25. 尽管中国 AI 厂商在基础设施和算力方面取得显著进展，但在前沿研究和原创性突破方面，与 OpenAI 等国际领先公司仍存在差距。
  26. 有一项提议主张将 Agent 目录统一修改为 .agents/skills，以解决当前目录结构混乱的问题，Codex App 已开始采纳此规范。
  27. 一款黑科技 Skill 可以控制安卓手机自动刷抖音，实现视频总结、点赞等功能，甚至可以DIY 豆包手机，该 Skill 可用于管理手机上的任何应用。
  28. Claude Sonnet 5 (代号 Fennec) 即将发布，据传其技术水平领先 Gemini 一代，价格更低但性能更强，拥有海量上下文窗口和 TPU 加速，并支持派生专业化子智能体。
  29. Vibe Coding 诞生一周年，Andrej Karpathy 认为 LLMs 的进步使得“vibe coding”（随性编码）成为可能，即 AI 辅助下的高效编码方式。
  30. 微软 CTO Kevin Scott 解释了 OpenAI 董事会解雇 Sam Altman 的原因，指出董事会成员的分歧、资源分配的张力以及研究方向的个人恩怨是关键因素。
  31. 李想盘点了 2025-2026 年初最具突破性的 AI 产品，包括 Claude Code、豆包手机、Manus、OpenClaw、MoltBook、Chrome Gemini，这些产品共同解决如何让 AI 真正落地执行任务的问题，特别是通过 GUI Agent 技术。
  32. GUI Agent 技术通过模拟用户界面操作，实现 AI 跨应用执行任务，是解决应用接口不开放问题的现实方案，预示着未来将是正规接口与 GUI Agent 混合模式的格局。
  33. 豆包手机助手、OpenClaw、Chrome Gemini 作为 GUI Agent 的代表，分别在手机、电脑和浏览器场景下实现了 AI 的跨应用操作能力。
  34. 有用户表示未来将更多地为 AI 提供工具，而非界面，专注于“Vibe coding”。
  35. Gemini in Chrome 的“自动浏览”功能，能够根据用户需求在网页中直接运行流程，如预约、填表等，得益于浏览器提供的结构化信息。
