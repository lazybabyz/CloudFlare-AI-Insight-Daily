## AI洞察日报 2026/1/18

>  `AI 日报` 



### **今日AI资讯**

1.  用户分享了使用 **Codex** 和 **Claude Code** 的经验。Codex 在写代码方面表现稳定且 **Token 量大**，但 CLI 体验不佳；Claude Code 易用性好，在**通用任务**上表现更优。用户建议 **OpenAI Codex** 团队反思产品发展方向。

2.  在清华举办的企业家 AI workshop 上，演示了使用 **Google AI Studio** 快速生成应用的流程：确定需求、AI 撰写 **PRD**、生成应用，并通过提示词迭代优化，整个过程不到10分钟。

3.  **ChatGPT** 开始在免费版和 Go 会员中测试**广告**，目前仅限于美国成年用户。广告将与内容分开且清晰标注，不会影响回复内容。Plus、Pro、Business 和 Enterprise 会员不受影响。

4.  一份关于 **OpenAI** 内部谈判的文件披露，**Elon Musk** 曾希望获得 OpenAI 股权以积累财富，但最终因其要求**单方面控制**公司而未能达成一致。Elon Musk 曾为此创建了“Open Artificial Intelligence Technologies”公司。

5.  **OpenAI** 宣布在 **ChatGPT** 的免费版和 Go ($8/月) 层级测试**广告**，并强调广告不会影响回答内容，且用户对话将对广告商保密。此举旨在探索一种能让用户免费使用 AI 的商业模式。

6.  **Kling Motion Control** 技术被提及，可实现**角色互换**并生成**创意视频**，展示了将真实表演转移到 AI 角色上的应用。

7.  用户对 **Codex CLI** 的一项功能表示关注：当任务需要较长时间且上下文空间耗尽时，该工具会**主动进行上下文压缩**，这与 Claude Code 的行为不同。

8.  **Kling Motion Control** 被展示为一种**无需盛装打扮**的视频创作工具，用户可以录制现有形象，并使用**精修照片**作为参考进行创作。

9.  一个使用 **Suno AI**、**Kling AI**、**NanoBanana** 和 **AfterEffects** 制作的 AI 音乐视频被分享。

10. **Sam Altman** 转发了 OpenAI 关于 **Elon Musk** 离职事件的声明，指出 Elon Musk **选择性地呈现信息**，而 **Greg Brockman** 和 **Ilya Sutskever** 曾努力尝试满足其对公司结构的要求。

11. **Kling 2.6** 通过提示词生成了一个**赛博朋克风格**的视频，描绘了游牧黑客在等离子体炙烤的沙漠中骑行，并将代码投影到空中。

12. **OpenAI** 正在 **ChatGPT** 免费版和 Go ($8/月) 层级测试**广告**，并承诺不会利用广告影响回答内容，同时**保护用户隐私**。Sam Altman 认为此举是满足用户对免费 AI 需求的一种尝试。

13. **OpenAI** 与 **Cerebras** 达成合作，预示着**更快版本的 Codex** 即将推出。

14. **ChatGPT** 的**记忆功能**得到了改进，能够更可靠地查找和回忆用户过往的聊天细节，例如食谱或健身计划。

15. **Kling 2.6 Motion Control** 被誉为具有**最佳真实感**的工具，能够实时生成完美的**面部表情**，预示着内容创作领域的新时代。

16. **Kling 2.6 Motion Control** 的一个教程展示了如何创建**潮流的混色视频**。

17. 用户使用 **Claude Agent SDK** **一天内**开发了一个基本的本地版 **cowork + manus**，并感叹 AI 时代的**极速开发效率**，预测2026年将是各类 **Agent** 井喷的一年。

18. **Kling 2.6** 的一个示例展示了如何创建**赛博朋克风格**的城市被外星舰队入侵的场景，包含高速运动镜头和末日般的氛围。

19. **Kling 2.6** 的 Prompt Studio 功能被展示，能够通过**图像生成视频**并带有原生音频，例如从高处俯冲穿过巨型建筑。

20. **Kling 2.6 Motion Control** 的用户分享了其创作的**逼真面部表情**和**即时角色切换**能力，认为这开启了内容创作的新纪元。

21. 用户分享了 **ChatGPT** 的**个性化设置**和**项目文件夹 Prompt 设置**，特别是使用 **GPT-5.1 Thinking** 以获得更客观的回答。

22. **Codex CLI** 新增实验性功能，允许用户在**代理工作时进行中断和引导**，使代理能近乎实时地适应新的指令。

23. 用户在寻求一个类似 **OpenCode** 的**轻量、开源的 Agent CLI**，该 CLI 能集成不同 AI Provider，如 OpenAI ChatGPT 和 GitHub Copilot。

24. **Kling AI** 的用户分享了使用该工具制作**AI 舞蹈视频**的教程和示例。

25. **ChatGPT** 的**记忆功能**得到了提升，可以更好地记住用户的聊天内容，如食谱和健身计划。
