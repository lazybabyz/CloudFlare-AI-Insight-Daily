## AI洞察日报 2026/2/22

>  `AI 日报` 



### **今日AI资讯**

1.  **Codex API** 提供了便捷的访问方式，只需运行 “codex app-server”。SIGKITTEN 分享称，Codex app-server 非常实用，他甚至基于此创建了一个 **iPhone 应用**，可以在网络内的任何地方生成并与 Codex 交互。他成功将 Codex 集成到 iPhone 应用中，并展示了部分实现效果。
2.  **Codex** 可用于**端到端的开发工作流**。Andrew Mayne 发现，他可以使用 OpenAI Codex 应用来控制 iPhone 模拟器，进行应用测试、截图抓取和调整，极大地简化了自动化测试的流程。
3.  **Codex 应用**受到了好评。Paul Solt 对此表示好奇，并询问大家正在使用哪种模型进行 **Model Harness**。
4.  **NotebookLM 移动应用**现已支持**自定义视频概览**功能，使用户可以更方便地在手机上观看教育性、基于来源内容且风格可爱的视频。
5.  OpenAI **团队**在各个项目上取得了显著的**积极进展**，这让团队感到非常自豪。
6.  **Codex 社区线下聚会**正在各地举行，OpenAI 开发者大使正在组织活动，鼓励开发者们在当地社区创建和发布项目，交流工作流程，并与使用 Codex 的同行建立联系。
7.  在一次与印度总理 **Narendra Modi** 的会谈中，双方讨论了印度在 **AI 领域**的巨大潜力。印度已成为 Codex 的**增长最快的市场**，周活跃用户在过去两周内增长了 4 倍。
8.  Vercel Developers 宣布 **Kling 视频模型**现已上线 **AI Gateway**，支持文本到视频、图像到视频、多镜头、首尾帧等多种生成方式，并提供了使用示例。
9.  **Google 发布 Gemini 3.1 Pro**，其**推理能力翻倍**，重新回到 AI 模型第一梯队。该模型在 ARC-AGI-2（新逻辑模式解决能力）上得分 77.1%，远超 Claude Opus 4.6 (68.8%) 和 GPT-5.2 (52.9%)。在 Humanity's Last Exam (高级学术推理) 和 GPQA Diamond (科学知识) 上也表现出色。
10. **Gemini 3.1 Pro** 在**编码和 Agent 方面**也得到了全面提升，LiveCodeBench Pro Elo 达到 2887，SWE-Bench Verified 得分 80.6%，APEX-Agents 得分 33.5%，BrowseComp 得分 85.9%。Google 还推出了针对 Agent 场景优化的 `gemini-3.1-pro-preview-customtools` 端点。
11. **Gemini 3.1 Pro** 在**某些维度**上并非最强，例如在 LM Arena 用户投票排名中，Claude Opus 4.6 在文本和编码类别中仍然靠前，在 GDPval-AA (专家任务) 上 Claude Sonnet 4.6 也大幅领先。
12. **Gemini 3.1 Pro API** 方面有几项实用更新，包括文件上传限制提升至 100MB，支持直接分析 YouTube URL，以及新增 `medium` 级别的 `thinking_level`。需要注意 `total_reasoning_tokens` 已更名为 `total_thought_tokens`。
13. Gemini 3.1 Pro 支持最多 **100 万 token 输入上下文**和 **6.4 万 token 输出**，并具备原生多模态能力。
14. Gemini 3.1 Pro 的**定价与 Gemini 3 Pro 相同**，200k token 以内输入 $2/百万 token，输出 $12/百万 token；超过 200k 则为 $4/$18。其性价比显著提高。
15. 普通用户可通过 Gemini app 和 NotebookLM 使用 Gemini 3.1 Pro，需要订阅 Google AI Pro 或 Ultra。开发者可以通过 AI Studio、Gemini API 等多种方式访问，模型标识符为 `gemini-3.1-pro-preview`。
16. **Sundar Pichai** 宣布 **Gemini 3.1 Pro** 发布，强调其在核心推理能力上的显著提升（ARC-AGI-2 得分 77.1%），并指出该模型在处理复杂任务方面表现出色，例如可视化困难概念、合成数据以及创意生成。
