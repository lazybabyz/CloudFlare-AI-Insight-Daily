## AI洞察日报 2026/1/12

>  `AI 日报` 



### **今日AI资讯**

1.  一款名为 NotebookLM 的 **AI 工具** 经过改造后，能够实现“一句话拆书”的功能。用户可以从 zlib 下载电子书，统一转换为 PDF 格式后自动上传至 NotebookLM。接着，该工具能自动提问、获取回答，并将 AI 生成的内容**转写成文章**，整个过程仅需用户提供书名。

2.  RT ICO 分享了使用 **Kling 2.6 的运动控制功能**，通过 Kling 官方的动作库模板生成。该功能能够精准跟随**各种角色和风格的动作**，并能细致地**还原视频中的表情**，可玩性很高。

3.  RT KANA 分享了使用 **Midjourney 的新模型 niji 7** 生成的图像，并用 **Kling 2.6** 制作了视频。与 niji 6 相比，niji 7 在**提示词的遵循度**、**细节分辨率**以及**线条的清晰度**方面都有提升，且**模型非常适合直接用于视频制作**。

4.  一条讨论指出，国产的**出海 Coding 产品**或使用 **tailwind CSS** 的产品，可以通过赞助的方式进行推广，因为该方式能带来较高的曝光度，每次博主发布内容都会附带赞助商的 **logo 墙**。

5.  RT 马天翼分享了 Linus Torvalds 使用 Google 的 **Antigravity** 进行“Vibe-coding”的案例，他实现了一个**Python 音频可视化工具**，并在项目介绍中提到该工具**基本是由 Vibe-coding 完成的**。

6.  RT Pierrick Chevallier | IA 对 **Kling 的文本到视频能力**表示惊叹，认为其能力每次都令人印象深刻。

7.  RT Tz 分享了一段关于高智商人群的“互怼”对话。前 OpenAI 员工 Vahid Kazemi 声称 **xAI 团队的业务能力比 OpenAI 强 10 倍**，而另一用户 roon 则幽默地回应称，Vahid Kazemi 的离职**同时提高了两家公司**（OpenAI 和 xAI）的**平均智商**。Denny Zhou 则评论称，即使是 GPT-5.2 或 Gemini 3 也**无法生成类似的回应**，并认为离 AGI 仍有距离。

8.  Tailwind CSS 的创始人透露，该项目**裁员 75%**，收入**下降 80%**。尽管如此，**几乎所有主流的 Vibe coding 产品**都依赖 Tailwind CSS。AI 的强大理解能力导致用户不再查阅文档，从而削弱了 Tailwind UI 等**商业产品的转化率**。文章呼吁需要一种更好的**资金分配方式**来维系这类重要的开源项目。在该消息发布后，**Google 已向 Tailwind CSS 捐赠**，但 OpenAI 和 Anthropic 尚未有动作。

9.  谷歌的 **Antigravity 服务**因用户滥用而开始对 **Pro 用户设置每周额度上限**，而 Ultra 用户则不受此限制。

10. **OpenAI 官方支持 OpenCode**，用户可以通过**浏览器授权登录**来使用 **GPT5.1 Codex** 和 **GPT5.2**，这一功能被认为非常方便。

11. RT Alin 分享了一个使用 **Kling 2.6** 制作的视频，视频内容为一个孩子躲在床下，巨大的三脚**外星人**正在摧毁社区，玩具四散，手电筒光束摇曳。

12. RT ゟ(yori) 分享了使用 **Kling 2.5 Turbo** 制作的 AI 视频，并提醒大家要小心，以免“掉下去”。

13. 文章讨论了需要**长时间运行的场景**，并列举了几个应用实例，包括**代码迁移**（从一种语言到另一种语言，且测试集完整）、**逆向代码**以及**模块化重构代码**（在测试集合完整的情况下）。评论中有人认为 **Codex** 能力强大且稳定，甚至在人肉指导下很难出现两次错误，并表示难以理解其他 Agent 的复杂性，考虑尝试使用如 GLM 等较弱的模型配合 **Ralph loop**。
