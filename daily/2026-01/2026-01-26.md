## AI洞察日报 2026/1/26

>  `AI 日报` 



### **今日AI资讯**

1.  **阿里Qwen3-TTS-12Hz-1.7B-CustomVoice**：阿里最新开源的 **Qwen3-TTS-12Hz-1.7B-CustomVoice** 模型可在本地笔记本上轻松运行，支持10多种主流语言，并能感知语调、情绪和上下文，同时支持**自定义和克隆音色**。更小的0.6b模型版本为本地用户提供了极大的便利。

2.  **Vision Pro 使用体验**：用户为 **Vision Pro** 配备了近视镜片，体验略优于隐形眼镜。在安装特定插件后，尝试了YouTube、Telegram和ChatGPT，并将其作为**移动办公的扩展显示器**，但长时间佩戴仍感不适。

3.  **OpenAI Codex 更新**：**OpenAI** 计划在未来一个月内发布一系列与 **Codex 编码模型**相关的更新，旨在加强在AI编码领域的竞争力。

4.  **Claude Code 辅助视频字幕生成**：通过 **Claude Code** 的 `omni-captions-skills`，用户可以快速下载视频并生成**中英双语字幕**，实现精准对齐，省去了传统字幕制作的繁琐步骤。

5.  **Claude Code 调用 Codex**：用户可以通过一个简单的Skill，在 **Claude Code** 中方便地调用 **Codex** 模型，实现**自然语言对话编程**，特别适合规划和修复Bug等场景。

6.  **Codex 集成 JetBrains IDEs**：**OpenAI** 已将 **Codex** 集成到 **JetBrains IDEs**（如IntelliJ、PyCharm等）中，用户可通过ChatGPT订阅在代码编辑器内实现**编码规划、编写、测试和审阅**等功能。

7.  **Codex Agent Loop 原理**：OpenAI 发布博文，详细介绍了 **Codex Agent Loop** 的工作机制，阐述了模型在用户提示和生成响应之间，如何**组装输入、运行推理、执行工具并反馈结果**。
