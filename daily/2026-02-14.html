AI洞察日报 2026/2/14

AI 日报

今日AI资讯

  1. Codex agentic sandbox for Windows 发布，这是全球首个专为 Windows 设计的 编码代理沙盒，允许代理在无需用户批准具体命令的情况下安全地进行工作。该功能已在命令行界面（CLI）上线，未来将推出 IDE 扩展和 Windows Codex 应用。

  2. Gemini 推出了一个 Skill，旨在帮助开发者使用 Gemini API，但用户认为其 实用性不高，因为对于非高频用户而言，资料和文档已足够使用。

  3. 在 Claude Opus 4.6 和 Codex 5.3 的对比评测中，Claude Opus 4.6 在“省心”方面胜出，而 Codex 5.3 则在“天花板”表现上获胜，尤其是在直接翻译和改写文章方面。

  4. Codex Spark 被评价为“感觉像生活在未来”，其 OpenAI 的新模型能够 几乎瞬间生成代码，极大地改变了开发体验，并已开始提供实验性访问。

  5. Kling 3.0 已在 Creati 上线，能够根据 一个提示词生成完整的电影序列，用户可通过参与活动或充值获得使用额度。

  6. Gemini 3 Deep Think 迎来重大升级，Google AI Ultra 用户可通过 gemini.google 或应用内的工具菜单访问。该模式专为 驱动实际应用 而设计，能够帮助研究人员解读复杂数据，工程师通过代码模拟物理系统。

  7. 此前关于 Claude Code 会根据模型更新 Prompt 的说法被澄清，经过 Codex 分析 Claude Code 客户端代码后，未发现 相应证据，该说法已删除。

  8. 用户对 Google 的 Gemini 3 Deep Think 模型印象深刻，称其生成的 SVG 鹈鹕骑自行车的图像 非常逼真。

  9. Ultra-low latency Codex 发布，OpenAI 的 GPT-5.3-Codex-Spark 模型已进入研究预览阶段，能够显著 加快开发速度。

  10. Gemini 3 Deep Think 已被早期测试者用于 解决严谨的现实世界应用，包括识别研究论文中的缺陷和优化半导体生长。

  11. Sundar Pichai 表示，Gemini 3 Deep Think 得到了重大升级，与科学家和研究人员紧密合作，以应对严峻的现实世界挑战，并在 ARC-AGI 和 Humanity’s Last Exam 等基准测试中取得突破性成果。

  12. Gemini 3 Deep Think 被展示了其 创造性应用，能够将手绘草图转化为可交互的原型设计，并生成用于 3D 打印的 STL 文件，用户可以利用它制作如笔记本支架等物品。

  13. 用户高度评价 谷歌新发布的 Gemini 3 Deep Think 模式，称其在分析 Codepilot 项目时，在 Next.js、性能优化、安全和交互体验 等多个维度都提供了深度且必要的优化建议。

  14. 谷歌基于 Gemini 3 的 Deep Think 模式 发布，在 ARC AGI 第二版 等多项指标上创下新高，相较于 Gemini 3 Pro 有显著提升，目前 Ultra 用户 可在 Gemini APP 中使用。

  15. Gemini 3 Deep Think 模式已正式发布，该模式能够驱动实际应用，帮助研究人员分析复杂数据，工程师通过代码模拟物理系统，并能将草图转化为 3D 打印的实际物品，此更新已向 Google AI Ultra 订阅用户推出。

  16. OpenAI 宣布将为 Codex Pro 用户在当天稍晚时候推出一项 特殊功能，Sam Altman 对此表示期待，并认为用户会非常喜欢。

  17. Codex 团队 以其 快速的开发速度 而受到赞扬。

  18. Codex 被评价为一款 优秀且功能强大 的日常开发工具，用户表示即使在复杂的工作流和长时间会话中，Codex 也能始终保持高质量输出。

  19. 消息称，Kimi 正在招聘 Coding Agent（类似于 Claude Code）的开发人才，并有大量招聘名额，感兴趣者可直接投递简历。

  20. Codex 被认为是 NVIDIA 提高生产力的重要工具，尤其是在结合 GPT-5.3-Codex 模型后，给工程师留下了深刻印象，他们认为 Codex 的能力正在快速发展，令人兴奋。
