AI洞察日报 2026/2/11

AI 日报

今日AI资讯

  1. GPT-5.3 Codex 展现跨语言应用重写能力：Christopher Ehrlich 分享了使用 GPT-5.3 Codex 将 1989 年的 SimCity C 语言代码库移植到 TypeScript 的成功案例。他表示，该过程几乎无需阅读代码和少量指导，最终成功在浏览器中运行了 SimCity，并感叹新世界的到来。

  2. Codex 应用的强大功能：CHOI 体验了 Codex 应用，称其“令人难以置信”。他表示，通过将一个想法在 ChatGPT 中提炼，然后复制到 Codex 的 Plan 模式，并选择其建议选项后直接运行，就能一次性构建出完整的应用。

  3. OpenAI 探讨广告策略：在最新一期播客中，OpenAI 广告负责人 Asad Awan 将与 Andrew Mayne 讨论 OpenAI 的广告原则，以及 ChatGPT 免费版和 Go 版本的广告如何扩大 AI 的普及范围。

  4. Codex 应用用户增长迅速：Sam Altman 透露，Codex 应用 在发布首周下载量超过 100 万，整体 Codex 用户上周增长超过 60%。OpenAI 计划在促销期结束后继续向免费和 Go 用户提供 Codex，但可能会调整使用限制，以确保更多人能够体验并进行开发。

  5. ChatGPT 广告测试启动：OpenAI 开始在美国部分免费和 Go 用户中测试 ChatGPT 广告。声明强调，广告不会影响 ChatGPT 的回答，并且会明确标识为“赞助内容”，与正常回复区分开。此举旨在让更多用户免费使用 ChatGPT，同时维护用户信任。

  6. OpenAI 发布超级碗广告：OpenAI 发布了其超级碗广告。

  7. Cursor 集成 GPT-5.3 Codex：Cursor 宣布 GPT-5.3 Codex 已在其平台上可用，并称其性能显著优于 5.2 版本，已成为许多工程师的首选模型。

  8. Gemini 应用动态征集：Gemini 应用团队正在征集用户在其平台上开发的各类应用，鼓励用户在回复中分享他们的项目。

  9. Sam Altman 回顾 ChatGPT 发展：Sam Altman 分享了 ChatGPT 发布初期的推文，对比了当时对 AI 助手的设想——从对话、问答、建议，到执行任务，再到最终发现新知识，感慨AI 发展的迅捷。

  10. 儿子利用 Vibe Coding 制作《我的世界》网站：一位家长分享了其儿子利用 Vibe Coding 制作一个《我的世界》资料查询网站的成果，该网站还包含后台管理功能，展现了兴趣驱动学习的力量。

  11. Codex 持续快速改进：atzy 分享其已将 Codex 作为日常开发工具，称赞其应用和模型的高效与快速，认为 Med/High 层级的速度已足够支持其工作流程。

  12. Codex 团队致力于改进：Tibo 表示 Codex 团队本周正全力投入工作，除大量小型优化外，还有一些令人兴奋的重大创新正在开发中。

  13. GPT-5.3 Codex 与 Claude Opus 4.6 对比：有博主测试对比 GPT-5.3 Codex 和 Claude Opus 4.6，普遍认为 Claude Opus 4.6 更强。但也有推荐组合使用的策略，例如用 Codex 5.3 制定计划，Opus 4.6 开发；或 Opus 4.6 写代码，Codex 5.3 审核。

  14. Vibe Coding 对初学者的吸引力：有观点认为，Vibe Coding 对编程新手或长期未编程者更具吸引力，能带来从零到一的兴奋感，其吸引力在不同编程水平和领域（前端/后端）的用户中有所差异。
