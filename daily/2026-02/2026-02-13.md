## AI洞察日报 2026/2/13

>  `AI 日报` 



### **今日AI资讯**

1.  **Claude Code 客户端代码分析结果更新**：经过对 Claude Code 客户端代码（已混淆但仍为明文）的分析，尚未发现 **Claude Code** 会根据模型更新 Prompt 的证据。此前关于此点的说法不准确，已删除相关帖子。但值得注意的是，**Claude Code** 的一些更新曾导致 Kimi K2.5 的 Cache 命中率降低，问题现已定位并修复，用户可继续在 **Claude Code** 中使用 Kimi K2.5。

2.  **OpenAI 发布 Ultra-low latency Codex**：**OpenAI** 研究性发布了 **GPT-5.3-Codex-Spark**，旨在提供超低延迟的 **Codex** 服务，让用户能够更快地进行开发。

3.  **Gemini 3 Deep Think 应用进展**：**Google** 的 **Gemini 3 Deep Think** 模式已开始显现成效，早期测试者正利用该模型解决严谨的现实世界应用问题，包括发现研究论文中的潜在缺陷和优化半导体生长。

4.  **Gemini 3 Deep Think 重大升级**：**Google** 宣布 **Gemini 3 Deep Think** 模式获得显著升级，该模式与科学家和研究人员紧密合作，用于解决复杂的现实世界挑战。升级后的模型在 **ARC-AGI** 第二版测试中取得了 **84.6%** 的创纪录成绩，并在 **Humanity's Last Exam** 测试中达到 **48.4%**（无工具辅助）。

5.  **Gemini 3 Deep Think 赋能实体制造**：**Google** 的 **Gemini 3 Deep Think** 模式可协助实体创作。通过一个边项目，用户可以绘制一个笔记本支架草图，**Deep Think** 将其编码为交互式原型工具，并生成 STL 文件，最终打印出实物支架。

6.  **Gemini 3 Deep Think 深度优化建议**：**谷歌**新发布的 **Gemini 3 Deep Think** 模式在分析用户 **Codepilot** 项目时，在 **Next.js**、进程优化、性能、安全及交互体验等方面均提供了深度且必要的优化建议。**归藏(guizang.ai)** 指出，**Gemini 3 Deep Think** 在 **ARC AGI** 第二版等指标上表现卓越。

7.  **Gemini 3 Deep Think 模式发布及性能提升**：**谷歌**发布了基于 **Gemini 3** 的 **Deep Think** 模式，该模式在各项指标上均创新高，尤其在 **ARC AGI** 第二版上表现优于 **Gemini 3 Pro**。目前，**Ultra** 用户可在 **Gemini APP** 中使用。**Google DeepMind** 强调该模式有助于解决科学、研究和工程挑战。

8.  **OpenAI Codex Pro 用户专属更新**：**OpenAI** 宣布将为 **Codex** 的 **Pro** 计划用户在当天晚些时候推出一项特别更新，**Sam Altman** 表示对此感到兴奋，并认为用户会喜欢。

9.  **OpenAI Codex Pro 用户特别更新预告**：**Sam Altman** 预告，**OpenAI** 将在当天晚些时候为 **Codex** 的 **Pro** 计划用户推出一项“特别的、令人愉悦”的功能。

10. **Gemini 3 Deep Think 加速科学研究**：**Google** 更新了 **Gemini 3 Deep Think** 模式，以进一步加速现代科学、研究和工程领域的发展。该模式在 **ARC-AGI-2** 上取得 **84.6%** 的成绩，并在 **Humanity's Last Exam** 上设定了新标准。

11. **Gemini 3 Deep Think 助力科学前沿**：**Google DeepMind** 升级了其专业推理模式 **Gemini 3 Deep Think**，以协助解决科学、研究和工程领域的挑战，并推动智能前沿发展。**Wang Lab** 在**杜克大学**正利用该模式设计新的半导体材料。

12. **Codex 团队的高效表现**：**Ahmed** 赞扬 **Codex** 团队的开发速度非常快。

13. **Codex 作为日常驱动的强大工具**：**Dennis Hannusch** 分享了他本周开始日常使用 **GPT-5.3-Codex** 的体验，认为其表现“非常出色”，尤其在复杂工作流和上下文管理方面，能够准确执行指令，并且在长时间使用后质量仍保持稳定。

14. **Kimi 招聘 Coding Agent**：**Kimi**（月之暗面）正在招聘 **Coding Agent**，类似于 **Claude Code** 的职位，有兴趣的人才可直接联系 **Kai** 投递简历。

15. **Codex 在 NVIDIA 驱动生产力**：**NVIDIA** 的工程师广泛使用 AI 编码工具，尤其是 **GPT-5.3-codex** 版本的 **Codex**，其能力令工程师印象深刻，并被视为提升生产力的重要驱动力。

16. **Codex 赢得工程师青睐**：**Craig Weiss** 认为 **Codex** 的成功来得比预期快，并且观察到他认识的许多顶尖工程师正在从 **Claude** 转向 **Codex**。

17. **AI 能力跨越临界点**：AI 创业者 **Matt Shumer** 认为，2026 年 2 月 5 日同时发布的 **GPT-5.3 Codex** 和 **Claude Opus 4.6** 标志着 AI 能力跨越了一个临界点，其对知识工作者的冲击比普遍预期的更早、更广泛。他强调了 AI 在编码领域的能力已达到“成品”级别，并且正迅速扩展到其他领域。
